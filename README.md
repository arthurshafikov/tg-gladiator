# Self Employed TG Bot

# Commands

## Docker-compose

Run the application
```
make up
```

Down the application
```
make down
```

---
## Tests

Run unit tests
```
make test
```

---
## Linters

Run linters (you have to have golangci-lint installed on your PC)
```
make lint
```

---
## Integration Tests

Run integration tests
```
make integration-tests
```

### Deployment command list

```php

# install bashrc_helpers
# configure git ssh key
# clone the repository
# make up

```
